# Context-Aware Audio Engine — النسخة اليمنية (تطبيق سطح مكتب حقيقي)

محرك صوتي تكيّفي يدمج **VAD + Ducking + التقويم الثقافي اليمني + قفل الصلاة** حسب `thinking.md`.
يعمل كتطبيق desktop حقيقي: ميكروفون + سماعات + مواقيت Aladhan.

## التشغيل الحقيقي (Windows)

```bat
run_desktop.bat
```

يولّد `assets/*.wav` تلقائياً إن لم تكن موجودة، ثم يفتح الواجهة.

أوامر مباشرة:

```bash
set PYTHONUTF8=1
python -m src.context_aware_audio.sound_synth   # توليد ملفات WAV مرة واحدة
python -m src.context_aware_audio.app            # واجهة سطح المكتب
```

```bash
python tests/test_engine.py             # 128 - منطق المحرك + فلتر الثبات

python tests/test_content_settings.py   #  41 - تنقية مفاتيح المحتوى
python tests/test_content_panel.py      #  40 - لوحة المحتوى في الواجهة
python tests/test_desktop.py            # 245 - الأصول/المشغل/VAD/الصلاة/الإعدادات/الواجهة
python -m src.context_aware_audio.simulate
```

الاختبارات نصوص تُشغَّل مباشرة (ليست pytest) — عمداً: بلا اعتماديات.
كلsuite بلا `sleep` إلا `test_content_panel.py`: مسار الواجهة يقرأ
ساعة الحائط لا طابعاً محقوقاً، فانتظاره فيها حقيقي بالضرورة.

كل اختبار ينشئ التطبيق ويحفظ يجب أن يغلّف `settings.writable_path`
بمجلد مؤقت. الملف الحقيقي مُتجاهَل في git، فالكتابة إليه لا تظهر في
`git status` بينما تقلب إعدادات المستخدم. 마지막 الاختبارات تحفظ بصمة
الحجم في أولها وتتحقق منها في آخرها.

## البناء كملف exe

```bat
build_exe.bat
```

النتيجة: `dist\context_audio.exe` (ملف واحد، نافذة، بدون سطر أوامر).
المجلدان `build/` و `dist/` مخرجات مؤقتة ويمكن حذفهما بأمان في أي وقت.

> **ملاحظة مهمة:** الملف كبير (248MB)، لذلك يستغرق **أول تشغيل نحو 30-40 ثانية**
> وهو يستخرج نفسه في مجلد مؤقت قبل أن تظهر النافذة. هذا طبيعي لا خلل.
> إن أردت تشغيلاً فورياً بدون استخراج، استخدم `build_exe.bat --onedir` (مجلد
> بدل ملف واحد) — Startup أسرع بكثير.

### تشخيص أعطال الـ exe

وضع `--windowed` لا يملك نافذة طرفية، فأي خطأ كان يختفي بلا أثر. لذلك
يكتب التطبيق كل شيء إلى `%LOCALAPPDATA%\ContextAudio\context_audio.log`:
بدء التشغيل، حالة المشغّل والميكروفون، المواقيت، وأي استثناء غير معالج.

يبدأ التسجيل تلقائياً، ويدوّر الملف نفسه عند تجاوز 1 ميغابايت. عند طلب
المساعدة أرفق محتوى هذا الملف.

## مزايا سطح المكتب

- **تشغيل/إيقاف** فوري، زر «بدء مع Windows» (يكتب bat في مجلد Startup).
- **عدّاد dB حيّ** + شريط قياس.
- **اختيار الميكروفون** من قائمة أجهزة الإدخال.
- **معايرة الميكروفون** (2ث صمت): ترفع عتبة الكلام فوق ضجيج الغرفة.
- **الصوت الرئيسي** + كتم رئيسي + EQ لكل فترة (ليل أخفض).
- **تنبيه لحظة الأذان**: نغمة قصيرة على قناة مستقلة، فلا يقطعها كتم الخلفية.
- **سيناريوهات مثبّتة**: كل زر يبقي إشارته ثوانٍ بد أن تختفي بعد نبضة.
- **الخطة اليومية تتحدث تلقائياً** عند تغيّر التاريخ + عرض الجمعة بدلاً من الظهر.
- **عمق الخفض**: شريط وثلاثة مستويات (خفيف 60% / عادي 70% / عميق 80%).
  عمق 90% غير قابل للتحقيق: عند 65dB يصبح الكتم تاماً (نقاش حامي)،
  فـ«عميق» تعني متحدثاً واحداً بصوت عالٍ أو تلفازاً، لا حشداً.
- **أرضية ضجيج متتبَّعة**: وسيط متحرك يرفع عتبة الكلام فوق الغرفة تلقائياً.
  المعايرة اليدوية ما زالت موجودة كبذرة، لكن التتبّع يتجاوزها خلال ثوانٍ.
- **تبديل الوقت**: ضع التطبيق بأي لحظة من اليوم وشاهده يغيّر الفترة
  والصوت وحالة الصلاة. الأزمنة المذكورة تعمل زمناً حقيقياً.
- **مسار المحتوى**: أحاديث وقصص الأنبياء تُبثّ في نوافذها (الفجر،
  الضحى، الغداء، المقيل، السهرة) لا فوق الخلفية مباشرةً.
- **الإعدادات تُحفظ** تلقائياً وتُستعاد عند التشغيل التالي.

## مسار المحتوى (أحاديث وقصص الأنبياء)

سرد مسجَّل، لا مولَّد: التطبيق لا ينتج صوتاً. تضع الملفات بنفسك في
مجلد المحتوى وتبدأ.

### أين الملفات وكيف تُسمّى

المجلد: `assets/content` في وضع التطوير، وداخل مجلد بيانات التطبيق
في وضع exe (ينجو من إعادة البناء). يمكن تغييره من الإعدادات.

التسمية: `<النافذة>__<الترتيب>__<العنوان>.<امتداد>`
مثال: `maqil_story__001__قصة يونس.mp3` — الترتيب اختياري، والنافذة
بأسماء الثوابت: `fajr_wisdom`, `duha_wisdom`, `dhuhr_reflection`,
`maqil_story`, `sahra_story`. زر «إعادة فحص المكتبة» يلتقط الجديد.

### متى يُبثّ ومتى لا

- **الهدوء شرط**: الغرفة دون 50dB لمدة 8-15ث حسب النافذة.
- **مرة في اليوم** للنوافذ القصيرة، وبفاصل زمني بين المقاطع للطويلة.
- **الضجيج يؤجّل**: ثلاث جلسات صاخبة متتالية تُلغي نافذة اليوم.
- **المقاطعة توقف وتتراجع**: كلام فوق 50dB يوقف السرد ويتراجع 3ث،
  ويستأنف بعد 5ث هدوء من لحظة التوقّف لا من آخر هدوء عام.
- **الصلاة فوق كل شيء**: تُنهي السرد وتصفّفه.
- **الخلفية تخفت** إلى 20% تحت السرد — استبدال لا ضرب، فالضرب مع
  منحنى الخفض كان يجعلها 2%.

### الأزرار

- **«شغّل الآن»** يتجاوز البوابة: طلب المجلس طلب صريح، والبوابة
  تحرس الانتباه لا المستخدم.
- **«تخطّي»** يقدّم التسلسل ويحسبه تخطياً لا «مرة في اليوم».
- **«كتم المحتوى»** يوقف الصوت والمؤشر معاً، ورفعه يستأنف من الموضع.

### ما لا يفعله

`music.set_pos` لا يقفز فعلياً على pygame 2.6.1، فالتراجع محسوب في
المحرك لا مطبَّق على الجهاز. الموضع الذي يعرضه هو مرجع المحرك،
لا قراءة الجهاز. المجلد الفارغ أو قاعدة تالفة أو مسار مشغول =
تطبيق يعمل بالخلفية وحدها ولوحة تشرح السبب.

### الإعدادات وملفاتها

`settings.json` يُنقّى عند القراءة والكتابة: كل قيمة تُحوَّل إلى نوعها
المتوقع ضمن مجالها، وأي مفتاح غير معروف يُهمَل. فملف يحتوي
`"use_mic": "false"` يُفهم كإيقاف، لا كنص غير فارغ. الكتابة ذرّية عبر ملف
مؤقت حتى لا يُبقى الملف مقتطعاً إذا توقفت العملية فجأة.

## منطق القرار (الأولوية)

1. **الصلاة** `PRAYER_MUTED`: كتم قبل الأذان 3د + Interlock + حظر 15د بعد الصلاة
2. **نقاش حامي** `DEBATE_MUTED`: dB≥65 + تداخل → كتم، عودة بعد 60ث هدوء
3. **ترحيب** `WELCOME`: نبرة مرتفعة → شلال بعيد 15% لمدة 8ث
4. **نوم** `SLEEP_SILENCE`: ليل + 5د بلا نشاط → صرار 20dB أو إيقاف
5. **هدوء مفاجئ** `CONTEMPLATION_FADE`: صمت 10ث → Fade-In ريح البن 3ث (مقيل) / الصوت اليومي
6. **Ducking** `DUCKED`: كلام عادي → خفض 70-90% حسب الشدة (Fade-Out 1ث)
7. **يومي** `DAILY_AMBIENT`: ملف الفترة + مستوى dB من الجدول

## ملاحظات

- المشغل `RealPlayer`: يفضل pygame (crossfade + fade ناعم)، ثم winsound، ثم log.
- الميكروفون `MicInput`: يعمل مع sounddevice (مثبت ويعمل على هذا الجهاز).
- المواقيت `prayer_provider`: يقرأ `city/country/prayer_method` من `EngineConfig`
  افتراضياً صنعاء + رابطة العالم الإسلامي، مع كاش وفFallback لأوقات تقريبية.
- كشف الترحيب: قفزة بداية + استمرار 0.3ث + كبح 3ث. الترقية: keyword-spotting لـ "أرحبوا/حياكم الله".
- نغمة الأذان على قناة مستقلة، فلا يقطعها كتم الخلفية.
- الملف التالف أو الناقص يُبلَّغ عنه مرة واحدة (`PLAY-FAILED`) ثم يُتخطّى حتى يتغيّر على القرص.
- في وضع exe، الملفات القابلة للكتابة (settings/kash/سجل) تذهب إلى `%LOCALAPPDATA%\ContextAudio`.
- `webrtcvad` اختياري: تحسّن دقة كشف الكلام لكنها تحتاج Visual C++ Build Tools
  للتثبيت (ملف مستقل `requirements-optional.txt`). بدونها يعمل المحرك على الطاقة فقط.
- `mixer.music` مسار أحادي: إما للخلفية وإما للمحتوى. إن لجأت الخلفية
  إليه في بناء pygame بلا `Channel` ككائن، يرفع `music_claimed` فيعطّل
  مشغّل المحتوى بسبب مسجَّل (لا صمت). `RealPlayer.stop()` يوقف `music`
  عندئذ فقط، وإلا لقطع السردَ عند كتم الخلفية.
- مسار المحتوى متعاون لا منافس: يمرّ من بوابة واحدة داخل محرك الخلفية
  ولا يدخل سلسلة الأولويات. الصلاة والنقاش الحامي يخرجان قبل البوابة.
